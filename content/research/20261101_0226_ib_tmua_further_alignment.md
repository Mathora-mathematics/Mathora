## 2. Precise learning targets and misconceptions

| Route | Verified learning target / exact code where available | Typical wrong inference / required guard |
|---|---|---|
| **IB AA SL, current** | Functions and calculus strands: build, analyse and communicate a valid functional model; justify a domain and check algebraic solution | Inverse/domain confused; treating an extraneous algebraic root as physically valid. **No claim of a current IB micro-code** until guide checked. |
| **IB AA HL, current** | Number/algebra + functions + calculus strands: reason symbolically about families of functions and validity of transformations | Squaring an equation without checking extraneous roots; assuming local result proves global claim. HL must be meaningfully deeper than SL; not merely bigger numbers. |
| **IB AI SL, current** | Statistics/probability and functions strands: interpret data/model parameters, use technology appropriately, qualify predictions | Correlation claimed as causation; extrapolation presented as certainty; numerical output without units or context. |
| **IB AI HL, current** | Statistics/probability and functions/calculus strands: choose and critically evaluate models, compare sensitivity and assumptions | Treating high R² or a fit as causal proof; ignoring sample bias, residuals and parameter sensitivity. Confirm HL-specific technique with current guide before activating. |
| **TMUA P1 MM1.3 / MM1.5** | Discriminant/completing square, quadratic inequalities; use them to infer number and range of solutions | Confusing \(D=0\) with two distinct roots; reversing inequality or missing endpoints. |
| **TMUA P1 MM8.2 / MM8.7** | Function transformations/compositions and interpreting simultaneous equations as graph intersections | Horizontal transformations reversed; mixing image and pre-image. |
| **TMUA P2 Arg1–Arg4** | Implication, converse/contrapositive, necessary/sufficient, quantifier negation | Converse taken as equivalent; “not all” mistaken for “none”; “or” treated as exclusive. **No symbolic logic or formal truth-table requirement.** |
| **TMUA P2 Prf1–Prf5 / Err1–Err2** | Direct/cases/contradiction/counterexample, proof ordering and invalid deductions | Cancelling a factor that could be zero; a few examples mistaken for proof. |
| **Cambridge 9231 P1 §1.1** | Relations of roots and coefficients of degree 2–4 polynomials, substitutions to transform roots | Signs of symmetric sums incorrect; division by a root without confirming nonzero. |
| **Cambridge 9231 P1 §1.3** | Summation formulae and method of differences / telescoping | Off-by-one limits; cancellation of the wrong boundary terms. |
| **Cambridge 9231 P1 §1.4** | Matrix operations up to 3×3; inverse, determinants and ordered composition of transformations | AB order reversed; det=0 ignored; treating determinant as signed area rather than absolute area scale. |
| **Pearson 9FM0 Core Pure §2.3** | Conjugate pairs for non-real roots of real-coefficient polynomials | Forgetting the conjugate root and therefore missing factors. |
| **Pearson 9FM0 Core Pure §3.3–3.6** | 2D transformations, invariant lines, determinants and inverses | Composition order reversed; invariant *line* mistaken for pointwise fixed line. |
| **Pearson 9FM0 Core Pure §4.1** | Roots/coefficient relations up to quartic | Reusing Cambridge numbering; forgetting repeated roots/multiplicity. |

**Further option gating:** Cambridge 9231 P3 mechanics §3.1–3.6 and P4 statistics §4.1–4.5 are separate component selections at AS; Pearson 9FM0 option codes 3A/3B/3C/3D and 4A/4B/4C/4D must be stored explicitly. An “FURTHER_MATHS/further” row with no board or option cannot be certified exam-aligned.
