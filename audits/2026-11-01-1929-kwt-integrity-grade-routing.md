## 1. Verified fix: Cambridge IGCSE 0580 target-grade scale

**Bug:** The installed `public.grove_admin_set_target` previously validated both GCSE and IGCSE using only numerical grades 1–9. However, the **2025–2027 Cambridge IGCSE Mathematics 0580 syllabus** awards **Core C–G** and **Extended A*–E**, whereas Pearson Edexcel International GCSE 4MA1 uses the numerical 9–1 scale. This would reject legitimate Cambridge letter targets and accept misleading Cambridge numerical targets.

**Change:** Added [`20261101_zz_cambridge_0580_target_grade_scale.sql`](../supabase/migrations/20261101_zz_cambridge_0580_target_grade_scale.sql) in commit [`88b5872`](https://github.com/Mathora-mathematics/Mathora/commit/88b5872de39e7cd7487980cdee759f92af87edf2) and successfully applied the production migration `cambridge_0580_target_grade_scale_20261101`. The new private pure validation helper accepts Cambridge 0580 Core C–G and Extended A*–E, while retaining the previous numerical GCSE/Pearson IGCSE, A Level, IB and TMUA rules. The public RPC still requires organisation-partner authorization. The helper is not executable by `anon` or `authenticated`.

**Recheck:** **16/16 read-only SQL fixture cases passed** (Core C/G allowed, Core B/9 rejected; Extended A*/E allowed, Extended F/7 rejected; Pearson 4MA1 grade 9 allowed, letter A rejected; AQA GCSE, Cambridge A Level, IB, TMUA and blank-grade clearing also checked). Installed RPC references the helper and still contains `private.is_partner` guard. There were **0 non-null existing target grades**; after migration the database still had **28 tasks, 4 task items, 5 evidence rows and 102 approved items**. No learner row was written by the migration or the verification.

**Official specification references:** [Cambridge 0580 2025–2027 syllabus](https://www.cambridgeinternational.org/Images/662466-2025-2027-syllabus.pdf), [Pearson Edexcel International GCSE 9–1](https://qualifications.pearson.com/en/qualifications/edexcel-international-gcses/the-9-1-grading-scale-explained.html). This fix addresses **0580 target validation**, not psychometric predicted-grade calibration or all possible grading systems. The staff UI still saves the programme first and the grade second; invalid input can cause a partial programme save. Consider a future atomic update or preflight validation.
