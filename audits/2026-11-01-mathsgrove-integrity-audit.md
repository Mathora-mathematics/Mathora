## Confirmed production bugs and fixes

1. **Baseline-to-practice repetition and editorial bypass — fixed for NEW task starts.** Before the change, all **240** active `pilot` practice-bank prompts exactly matched their route's 20-question baseline prompts; **4 already assigned** practice items were repeats of baseline questions. `public.grove_task_start` previously selected `active` items without checking `review_state='approved'` or excluding baseline-bank prompt text. The new `supabase/migrations/20261101_guard_approved_nonbaseline_practice.sql` adds **both predicates to both the eligibility count and the assignment query**, retaining board matching and per-student assignment-history checks. Existing active/completed tasks are returned unchanged; existing evidence, marks, answers and records remain intact. Applied successfully to live Supabase and verified the installed function has 2 approval guards and 2 baseline exclusions. Historical 4 repeated assignments remain as audit evidence and were not altered.

2. **Edexcel IAL P1 board mismatch — fixed.** Previously `private.grove_board_compatible('Pearson Edexcel IAL WMA11 P1','Pearson Edexcel IAL WMA12 P2')` returned `true`, allowing P1 questions to be routed to a P2 student. `supabase/migrations/20261101_exact_ial_unit_compatibility.sql` now requires `WMA11` for WMA11-specific content. Applied live and verified **P1/P2=false**, **P1/P1=true**, **UK GCE 9MA0 vs IAL=false**, **Cambridge 9709 match=true**. No student or question rows changed.

3. **Regression coverage added.** `scripts/check-approved-practice-gate.mjs` statically checks the newest task-start migration for both approval/baseline guards, historical repeat and board filters, and the newest board function for strict WMA11/9MA0 matching. `.github/workflows/pages.yml` runs it with existing site, evidence and content checks. Static tests are not a substitute for authenticated browser and RPC tests.
